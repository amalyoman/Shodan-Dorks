# Java Sample Code

This directory contains sample Java programs demonstrating basic Java programming concepts.

## Files

### HelloWorld.java
A simple "Hello World" program that demonstrates:
- Basic Java syntax
- String variables
- For loops
- Method definitions and calls
- Console output

**To compile and run:**
```bash
javac HelloWorld.java
java HelloWorld
```

### Calculator.java
A more comprehensive example demonstrating object-oriented programming:
- Class definition and constructors
- Private fields and public methods
- Method parameters and return values
- Exception handling with try-catch
- Mathematical operations using Math library

**To compile and run:**
```bash
javac Calculator.java
java Calculator
```

## Requirements
- Java Development Kit (JDK) 8 or higher

These samples cover:

- Error handling
